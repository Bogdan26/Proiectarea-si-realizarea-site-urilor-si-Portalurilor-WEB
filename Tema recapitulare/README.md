1. Pentru URL-ul API-ului am folosit: https://jsonplaceholder.typicode.com/photos?_limit=12 pentru a preluat primele 12 fotografii și am utilizat proprietățile titlu și url pentru a genera dinamic galerie de fotografii.
2. Deoarece am folosit API-ul public JSONPlaceholder, care oferă suport nativ pentru Cross-Origin Resource Sharing și returnează antetul Access-Control-Allow-Origin: \*, am putut executa cereri fetch direct din frontend, fără a necesita configurări suplimentare de server sau proxy.
3. Pentru GET am implementat funcția getPhotos() în care se face fetch la obiectele din API iar în funcție de răspunsul primit (response.ok), dacă este valid afișăm informațiile în frontend, dacă nu, preluăm eroarea folosind response.status. De asemenea am mai tratat cazul în care lista este goală (result.length === 0), prin afișarea mesajului corespunzător.
4. Pentru POST am adăugat la fetch headers: { 'Content-Type': 'application/json' } deoarece datele trimise sunt sub formă de JSON iar la body: am folosit JSON.stringify(data), am transformat datele luate din formular în formatul acceptat de server. Am verificat răspunsul primit folosind if (response.status === 201 || response.ok), dacă răspunsul este unul bun am continuat la crearea și adăugarea fotografiei în DOM iar în caz contrar am afișat mesajul de eroare.
5. Pentru a evita duplicarea codul am folosit funcția addPhotoDom(el) în care am creat toate elementele necesare pentrul blocul fotografie pe care le-am adăugat în frontend. Funcția fiind apelată atât la GET cât și la POST.
6. Pentru POST am validat câmpurile formularului, titlu (folosind if (title.length < 3 || title.length > 200)) respectiv a câmpului url (folosind blocul try, catch și constructorul new URL(url)).
7. Am mai adăugat funcționalitate de căutare în timp real după valoarea titlului fotografiei folosind funcția searchPhotos() și ștergerea fotografiei folosind funcția deletePhoto() introducând conceptul delegării evenimentelor.
8. La design am folosit normalize.css pentru resetarea stilurilor implicite ale browserului, CSS grid pentru responsivitate împreună cu media queries.
9. În HTML am folosit elemente semantice precum main, section, figure, figcaption, header și footer.
10. În cazul formularului am folosit atributul name pentru input-uri pentru a extrage valorile și a le trimite pe server cu ajutorul obiectului FormData în JavaScript.
